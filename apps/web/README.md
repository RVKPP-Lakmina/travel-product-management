# apps/web

The React SPA for the Travel Product Management System — Vite + Tailwind
v4 + shadcn-style components, feature-folder layout under `src/features/`
(`products/`, `ai/`, `auth/`, `dashboard/`, `export/`).

See the [root README](../../README.md) for setup, architecture, and the
security-controls overview. Scripts: `pnpm dev`, `pnpm build`, `pnpm lint`.
